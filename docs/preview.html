粒子群优化算法（Particle Swarm Optimization, PSO）由 Kennedy 和 Eberhart 于 1994 1995 年提出。该算法具有 O(n log n) 的时间复杂度，是目前最流行的群体智能算法之一。其核心思想是：群体智能源于个体间的信息共享。

1.1 行内代码与代码块

在终端执行 pip install numpy 即可安装依赖，修改 config.json 中的参数可以调整算法设置。

import numpy as np
from typing import Callable, Tuple

class ParticleSwarmOptimizer:
    """PSO optimizer implementation"""

    def optimize(self, dim: int = 30,
                  bounds: Tuple[float, float]) -> Tuple[np.ndarray, float]:
        pos = np.random.uniform(*bounds, (50, dim))
        for t in range(1000):
            # Evaluate fitness
            fit = np.sum(pos**2, axis=1)
            best_idx = np.argmin(fit)
        return pos[best_idx], fit[best_idx]
